# 历史资料归档

`kuka_iwaa/` 中的两个文件是早期副本，已从活动驱动目录移出。当前 KUKA 驱动仍为
根目录 `kuka_iwaa/kuka_iiwa.py`，当前桥接入口仍为
`kuka_iwaa/cartesian_teleop_bridge.py`。归档代码不参与包安装和运行。

保留这些历史副本便于追溯旧协议，不删除共享模型、SDK、第三方许可证或仍有引用的后端。

`docs/` 保存迁移前的操作长文和带日期的审查、测量记录。它们只用于追溯，里面的旧路径、环境名和测试结果不能替代当前使用说明或本轮验证。原文入口保留短链接；当前资料从 [文档索引](../docs/README.md) 进入。
